# Penggunaan GitHub dalam Software Quality

## Deskripsi
GitHub digunakan sebagai alat bantu dalam pengembangan dan pengujian software untuk menyimpan kode, dokumentasi, serta mempermudah kolaborasi.

---

## Fungsi GitHub

### 1. Repository
Digunakan untuk menyimpan seluruh source code aplikasi rental PlayStation pada folder src.

---

### 2. Version Control (Commit)
Setiap perubahan pada project disimpan dalam bentuk commit.

Contoh:
- add: struktur folder
- add: source code rental ps
- add: testing documentation

---

### 3. Dokumentasi
GitHub digunakan untuk menyimpan dokumentasi seperti:
- SKPL
- Review software
- Testing

---

### 4. Pengujian Software
Hasil pengujian disimpan pada folder testing, sehingga mudah dilacak dan dianalisis.

---

### 5. Kolaborasi
GitHub memungkinkan kerja tim dalam satu repository yang sama.

---

## Penerapan pada Project

Dalam project ini GitHub digunakan untuk:
- Menyimpan source code Laravel pada folder src
- Menyimpan dokumen SKPL pada folder skpl
- Menyimpan hasil review pada folder review
- Menyimpan hasil testing pada folder testing

---

## Kesimpulan
Penggunaan GitHub membantu meningkatkan kualitas software karena semua proses pengembangan, pengujian, dan dokumentasi tersimpan secara terstruktur.
