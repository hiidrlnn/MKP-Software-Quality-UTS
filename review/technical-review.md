# Technical Review

Technical Review adalah proses evaluasi terhadap aspek teknis dari software, seperti struktur sistem, penggunaan teknologi, dan performa aplikasi.

Pada aplikasi rental PlayStation ini, technical review dilakukan dengan melihat:

- Struktur project Laravel (MVC)
- Penggunaan controller dan model
- Pengelolaan database (Rental, Unit, Payment)
- Tampilan frontend menggunakan Tailwind CSS

Contohnya:
- Memastikan struktur MVC sudah terpisah dengan baik
- Memastikan controller tidak terlalu kompleks
- Memastikan data tersimpan dengan benar di database

Selain itu, juga dilihat apakah aplikasi mudah dikembangkan dan dipelihara ke depannya.

Tujuan dari technical review adalah memastikan sistem tidak hanya berjalan, tetapi juga memiliki kualitas yang baik dari sisi teknis.
